# Open Flags: Cedar Peak Dental

Unresolved items for this install: contradicted facts, unverified facts that work is waiting on, pending client answers, broken links, and anything oversight has questioned. If it is unresolved and someone needs to own it, it lives here until it closes.

## Flag format

Every flag has all six fields. A flag missing an owner or a next check date is not a flag, it is a rumor, and it gets completed or removed at the next review.

| Field | Meaning |
|---|---|
| Flag | The unresolved item, stated as one fact or one question |
| Raised | Absolute date the flag was opened |
| Owner | The person or lane responsible for resolving it |
| Next check | Absolute date it will next be checked or chased |
| Blocks | What cannot proceed until it resolves, or "nothing" |
| Status | Open, Waiting on client, Waiting on verification, Resolved |

## Review discipline

- Flags are reviewed on the install's weekly rhythm. A flag past its next check date without an update is escalated by the lane lead.
- A contradiction between two records in this memory is always a flag. It is resolved against the live source, and the losing value is handled per the change note rules in the file it lived in.
- A flag that turns out to involve client data in the wrong layer is handled the same day under the Team Pack memory contract leakage procedure.
