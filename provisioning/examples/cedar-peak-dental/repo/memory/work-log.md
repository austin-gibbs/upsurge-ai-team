# Work Log: Cedar Peak Dental

The index of work for this install. The Surge Command Desk is the live board of record; this file is the durable index that points into it, grouped so the install's history reads in one place.

## How this file is maintained

- Entries are written by the completion event: when a Desk project moves to Done with its completion note, a row is added here. Nothing is added by hand for work that has not completed.
- In progress and waiting work is not listed here. It lives on the board. This log is the record of what was delivered.
- Every row links to its Desk project. If a link breaks, the row stays and the break is flagged in `open-flags.md`.
